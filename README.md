# cc-resources
Resources for Claude Code.

## Plugin Marketplace

This repository is a Claude Code plugin marketplace.
Add it once, then install plugins from it:

```
/plugin marketplace add TutanDev/cc-resources
/plugin install lowy-dmf@cc-resources
```

| Plugin | What it does |
|---|---|
| [`lowy-dmf`](plugins/lowy-dmf/README.md) | Löwy's Method + Domain Modeling Made Functional: decompose by volatility, classify layers, validate call chains, model domain types in C#, audit existing code with verified multi-agent reviews, and enforce the rules with fitness tests |
